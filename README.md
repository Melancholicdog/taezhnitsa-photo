# Таёжница × Медоед — фотогалерея

Простой сайт-каталог с фото продукции двух брендов, без цен, корзины, форм и базы данных.

## Добавление фотографий
- Для «Таёжницы» откройте папку photos/taezhnitsa
- Для «Медоеда» откройте photos/medoed
- Нажмите Add file → Upload files, выберите JPG/PNG/WEBP, затем Commit changes.
- После загрузки сайт автоматически пересоберётся. Название файла станет названием фотографии.

## Включить сайт
GitHub → Settings → Pages → Build and deployment → Source → GitHub Actions.

Ожидаемый адрес после успешной публикации:
https://melancholicdog.github.io/taezhnitsa-photo/

Важно: GitHub Pages может быть недоступен без VPN у части российских провайдеров. При необходимости эти же статические файлы можно размещать на российском хостинге.
